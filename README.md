# Dash Platform Architecture Map

An interactive, source-linked overview of Dash Platform's architecture, from
Tenderdash and Drive through GroveDB proofs, DAPI, SDKs, and client-side
verification.

The site is intentionally self-contained: GitHub Pages serves the single
[`index.html`](index.html) file without a build step or backend.

## View the map

Open the [live GitHub Pages site](https://pastapastapasta.github.io/dash-platform-architecture/).

Click any component to see its responsibilities, implementation details,
related components, and links to the relevant Dash source repositories.
